# 客序 UI 交互原型

本目录保存 2026 年 11 月 13 日讨论、修改后的 UI 页面。四端在同一个入口中切换，可独立用浏览器、VS Code、其他编辑器或 agent 打开和修改。

## 文件

| 文件            | 用途                                                             |
| --------------- | ---------------------------------------------------------------- |
| `index.html`    | 主入口，包含老板小程序、员工小程序、老板网页、员工网页           |
| `styles.css`    | 配色、字体、卡片、四宫格、列表、底部图标和响应式排版             |
| `app.js`        | 示例数据、角色导航、表单、弹窗、搜索筛选、本地存储和图表         |
| `overview.html` | 参考草图的总览：老板小程序四页一排、员工四页一排、下方两个网页端 |

## 打开方式

可直接双击 `index.html`。更推荐用编辑器的静态服务器或以下命令预览，确保本地存储及总览内嵌页面行为一致。无需安装 npm 依赖、启动主项目、配置数据库或 API Key。

在仓库根目录运行：

```sh
python -m http.server 5189 --bind 127.0.0.1 --directory ui
```

Windows 也可以使用 `py -m http.server 5189 --bind 127.0.0.1 --directory ui`。

浏览器打开：

- 交互入口：`http://127.0.0.1:5189/`
- 所有页面布局总览：`http://127.0.0.1:5189/overview.html`

GitHub 的文件页面展示源码；需下载或克隆到本机后预览。

## 角色和页面链接

| 入口         | 相对地址                          |
| ------------ | --------------------------------- |
| 老板小程序   | `index.html?role=0`               |
| 员工小程序   | `index.html?role=1`               |
| 老板网页     | `index.html?role=2`               |
| 员工网页     | `index.html?role=3`               |
| 老板知识库   | `index.html?role=0&page=知识库`   |
| 员工顾客列表 | `index.html?role=1&page=顾客信息` |

`page` 指定初始页面，`embed=1` 隐藏演示外壳，供 `overview.html` 内嵌展示。

## 已包含的页面与交互

- 门店按顾客人数、员工人数、今日销售额升降序排序，省、市、区县逐级筛选；地理选项仅覆盖虚构门店所在地区。
- 门店详情含门牌地址、负责人、联系方式，以及当日、当周、当月销售额。
- 员工首页的门店名称、地址和电话可编辑，员工小程序与网页共用保存内容。
- 老板顾客页按一段、二段、三段、四段时期分类；员工小程序使用手绘稿的单列横条，姓名、宝宝月龄、详情入口并排，搜索位于右上角。
- 顾客档案包含微信号、联系方式、消费门店、累计金额、最近和下次联系时间，支持编辑，不展示维护类标签。
- 知识库以两行两列展示产品、服务、专业、其他四类，支持分类、搜索和新增编辑。
- 商品有独立填写入口和完整纸尿裤样例；新增按钮为“填写商品信息”，已移除“适用门店”字段。
- 小程序底部含线性图标，主页面已移除顶部“返回上一页”；弹窗右上角有固定关闭按钮。
- 员工网页展示近七日销售额、客户增长量柱状图；老板经营趋势显示每日金额和七日合计，可展开每日明细。

## 给编辑器和 agent 的说明

- 这是原生 HTML、CSS、JavaScript 原型，依赖三个同目录文件，不依赖仓库的 React、Next.js、Vinext 或 Cloudflare 运行时。修改此目录不会自动修改主应用。
- 页面结构和模块函数集中在 `app.js`，样式集中在 `styles.css`；四端通过 `configs` 和 `role` 区分。
- `render()` 负责页面渲染，`content()` 选择模块；顾客、商品、知识库、门店及图表均有对应函数，可搜索函数名定位。
- 保留已经确认的四宫格、双列布局；员工小程序顾客列表单独使用横向单列样式。
- 所有门店、客户、商品与经营数据均为虚构示例，图表日期固定为 2026-11-07 至 2026-11-13，不连接真实微信、登录、模型或数据库。
- 修改数据保存在当前浏览器的 `localStorage`（键：`kexu-prototype`），跨设备或浏览器不自动同步；“我的”或“AI 与设置”可重置全部示例。
- 不要把本地浏览器数据导出后当作源码示例提交；仓库只保存源码中预设的虚构数据。
