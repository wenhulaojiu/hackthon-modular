# 新活动

入口：`campaign.tsx`，从「总览」页顶部的「新活动」卡片进入。

职责：创建营销活动（名称 + 推送内容），按客户阶段、标签、偏好关键词圈选目标客户，一键生成 `kind:'marketing'` 的推送任务。

推送任务不直接发送：生成后跳到「客户跟进」页，沿用既有的单条发送或「一键回复全部」批量管线逐条核实回执。同名待推送任务不会重复创建；演示客户在发送环节会被既有校验跳过。

关联文件（相对于仓库根目录）：lib/types.ts（Task、PageId）、lib/domain.ts（today）。

验证：在仓库根目录运行 `npm run typecheck`、`npm test`、`npm run build`。界面修改还需通过总览页卡片进入本页，验证空客户、已选客户、重名任务跳过等状态。
