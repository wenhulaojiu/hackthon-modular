# 销售小程序 v1 · UI与交互说明

## 面向谁

销售使用手机管理本人客户，老板通过独立网页看全店。此版本只展示销售侧，不包含老板端或客户使用端。

## 页面与入口

| 页面 | 展示或交互 |
|---|---|
| 首页 | 个人销售额、客户/回访/疑难数量、快捷入口、待回访与待解答卡片 |
| 我的客户 | 姓名和宝宝昵称搜索、全部/今日回访/新客户筛选、进入客户详情 |
| 客户详情 | 来源B与导购归属、消费与预算、宝宝资料、沟通与跟进记录 |
| 回访待办 | 待跟进客户列表，进入档案记录反馈 |
| 跟进记录 | 输入文字及下次日期，文字保存到本次演示内存；日期控件仅作输入示意，未保存和调度提醒 |
| 消费登记 | 选择客户、输入正数金额与商品，校验后提示演示提交，不写真实订单 |
| 补充客户档案 | 手动新增虚构演示客户；正式自动建档入口在B电脑服务 |
| 疑难问题 | 展示B转A的待解答问题，模拟答案匹配和回复状态，不执行真实收发 |
| 导购建议 | 固定文案展示自然分句与复用已知月龄、预算，不调用模型 |
| 我的 | 导购、门店、A/B示例关系、个人表现与权限说明，重置演示 |

## A/B关系

- A为销售自己的私人微信，用于人工解答。
- B为客户添加的对客个人微信，系统接入B。
- 目标流程：客户问B → B转给A → 销售用A回答 → B匹配问题并回复原客户。
- 没有第三个助手微信号，导购小程序不负责直接读取微信好友或消息。

## 视觉与交互

沿用客序绿色主色与母婴经营场景，手机宽度适配，底部四个导航：首页、客户、疑难问题、我的。采用短文案、客户卡片、清晰状态和独立表单，区分经营维护与微信内人工回答。

## 后续真实接入范围

正式小程序界面实现、微信登录绑定、员工与门店权限、来源销售归属、云同步与真实客户接口，均不能由此预览替代。A/B本地功能已有独立首版代码，其实机验收和后续能力请查看对应产品功能与使用说明。
