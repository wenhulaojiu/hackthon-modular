# v1 · 销售端 UI 交互预览

[在线打开](https://kexu-sales-mobile-preview-1113.webhulaojiu.chatgpt.site/) · [查看UI源码](index.html) · [界面与交互说明](UI说明.md) · [返回小程序目录](../README.md)

## 怎么看

- 在线：其他设备用浏览器访问上方网址，并登录站点所属的同一个ChatGPT账号。
- 离线：下载本目录的 `index.html`，使用浏览器打开；无需安装依赖。
- GitHub页面展示HTML源码，点击文件不等于运行预览。

## 可以体验

首页快捷操作、客户搜索与筛选、客户及宝宝档案、记录跟进、消费登记校验、新增演示客户、A/B疑难问题回答演示，以及导购个人页面。

## 预览限制

- 所有数据均为固定虚构样例，展示的客户数量、统计金额和日期不代表真实业务，也不一定随演示操作重新计算。
- 新增客户、跟进和问题状态仅保存在本次页面内存，刷新后恢复；消费登记仅校验输入并提示，不生成真实订单。
- 疑难问题中的 `DEMO-1024` 是界面示意编号；真实本地版当前要求完整问题UUID，不能用该演示编号发送。
- 没有真实登录、员工权限、云端同步、微信收发或AI请求。
- 自然分句及不重复询问已有资料只在固定文案中示意，不表示已接通真实自动回复策略。
- 此文件是HTML原型，不能直接作为原生微信小程序导入发布；正式小程序仍需开发。

预览源为 `index.html`，在线托管副本与其内容一致。
