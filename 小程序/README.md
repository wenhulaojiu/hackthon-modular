## 在线查看

[打开销售小程序在线预览](https://kexu-sales-mobile-preview-1113.webhulaojiu.chatgpt.site/)

当前托管为账号私有，需要登录拥有此站点的同一个ChatGPT账号；不需要本机服务器保持运行。该入口不使用先前的localtunnel临时通道。如果外部网络无法访问，使用下面的离线方式。

## 下载到本机查看

进入 [v1文件夹](v1-销售端UI预览/)，下载 [index.html](v1-销售端UI预览/index.html)，完整保存后使用浏览器打开即可。GitHub文件页默认显示源码，不会直接运行HTML。

也可在下载仓库后运行：

```powershell
python -m http.server 5185 --bind 127.0.0.1 --directory "小程序/v1-销售端UI预览"
```

然后访问 http://127.0.0.1:5185/ 。此地址是当前设备的本地地址，不是分享链接。
