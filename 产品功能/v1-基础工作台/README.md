# v1 · 基础工作台功能说明

本文件归纳现有基础功能，不对应名为v1的软件Release。

## 产品用途

商户整理客户档案、导入聊天、维护门店知识、确认消费并安排跟进。当前代码以网页工作台和Windows电脑本地服务为基础，不包含完整销售小程序和老板团队管理系统。

| 模块 | 功能 |
|---|---|
| 总览 | 查看经营统计、客户和任务概况；消费确认后才进入相应统计 |
| 客户档案 | 客户基本资料、聊天、标签、备注、画像与跟进资料 |
| 母婴场景 | 宝宝档案、月龄里程碑、母婴演示客户与回访安排 |
| 微信数据 | 选择私聊和日期主动提取；批次导入、重复消息去重、通用聊天文件导入 |
| 文件上传 | 解析支持的文档和表格，整理到客户、商品或知识库，导入本身不自动调用AI |
| 自动建档 | 本机接待启动且开启自动接待新私聊后，根据有效新增好友提示或首次真实入站新文本建立档案 |
| 商品与知识库 | 商品、服务、FAQ与文档知识，作为接待回答的依据 |
| AI辅助 | 按配置生成画像、导购建议、回复与消费候选；无法可靠回答时转人工 |
| 自动回复 | 支持草稿审阅和配置后的自动发送；人工接管、营业时段、等待与冷却等规则 |
| 消费管理 | 区分候选、确认、退款和排除；付款卡片及购买意向不能直接当收入 |
| 客户跟进 | 回访计划、待办、跟进记录；待办不等于已自动给客户发送消息 |
| 数据与模型设置 | 备份导出、模型配置、连接测试、服务端加密保存模型密钥 |

## 使用前提与边界

- Windows本地微信读取与发送需要B所登录的电脑及服务运行，组件另行安装启用。
- 普通网页或小程序不能替代本地服务读取个人微信。
- 自动建档不代表已实现来源销售自动绑定、团队权限或云同步。
- 默认演示数据为虚构资料，不能当真实业绩。
- 已有部分单会话实机记录，不等于多销售、规模并发或长期无人值守验证。
- 导入资料、消费候选和AI建议仍需商户核对。
