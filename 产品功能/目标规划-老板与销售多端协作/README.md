# 目标规划 · 老板网页与销售小程序

本目录描述待开发目标，不是已实现或已发布版本。A/B本地人工协助已有首版代码，但不能据此认为下面团队能力已经完成。

| 使用端 | 目标功能 |
|---|---|
| 老板网页 | 全店经营总览、销售业绩、全店客户归属、消费与回访、疑难问题、员工及知识库管理 |
| 销售小程序 | 自己的客户、宝宝档案、消费登记、回访待办、个人经营情况与疑难问题记录 |
| B电脑服务 | 绑定门店和销售及私人号A，自动建档、上传授权数据、执行微信收发 |
| A销售私人微信 | 接收B的疑难问题、输入答案，再由B回复原客户 |
| 统一后台 | 员工身份、门店隔离、客户权限、来源销售自动绑定、同步去重、版本冲突及审计 |

## 客户归属与数据同步

客户添加B，由B电脑发现有效事件后建档；目标是按B绑定的销售自动归属，不需要老板分配。电脑同步至云端后，销售小程序看本人授权业务，老板网页看全店。现有本地建档尚不能替代这套绑定与同步机制。

## 需要明确的业务规则

跨销售重复客户的主负责人、离职交接、消费审核、业绩归因和老板查看聊天原文的范围仍需确认。
