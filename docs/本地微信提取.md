# 客序本地版与微信提取

本地版把工作台、客户资料、聊天和本地 D1 数据库存放在当前电脑。手动 AI 在点击时调用模型；主动启用本机回复后台后，白名单新消息也可能触发模型请求。默认没有微信发送器，只会生成草稿；项目不会自动确认营业收入。后台与发送网关说明见 [自动回复与本机验证](自动回复与本机验证.md)。

## 开始使用

1. 安装包含 npm 的 Node.js 24 或更新版本。将下载包完整解压到自己的可写目录，不要直接在 ZIP 中运行。
2. 双击 `启动客序.cmd`。首次启动会安装项目依赖、创建本地应用加密配置、构建运行配置，并按项目 Drizzle 日志初始化本地数据库；后续复用已准备的内容。
3. 服务确认就绪后只打开 `http://127.0.0.1:5173/`。保留启动窗口，使用 Ctrl+C 停止本次服务。5173已被占用时会停止，不会打开或连接不相关程序，也不会自动改用其他端口。
4. 需要普通微信提取时，再单独双击 `安装微信提取组件.cmd`。它只准备公开源码和独立 Python 依赖，**不扫描微信、不读取消息、不生成密钥**。
5. 保持 Windows 微信已登录，在本地工作台中选择好友私聊与时间范围，再主动点击提取。首次使用前核对账户和联系人；重名时使用准确的会话标识，不静默选择第一个。

首次依赖安装和下载需要网络。安装失败时保留窗口和日志，根据错误处理后重试；不要重复执行建表SQL或删除整个数据库来绕过错误。

## 微信与 Python 环境

提取组件使用用户指定的 [yeklongdi/wechat-chat-export](https://github.com/yeklongdi/wechat-chat-export)，固定提交 `d82f241e88e9357dc3a553c958ef516605bb85be`。上游声明支持 Windows 微信4.x，并核对过4.1.6.46的会话目录。本项目已在4.1.15.56完成文件传输助手当天1条自测消息的只读回读，唯一自测标记命中1次，字段、验证报告和摘要校验通过；没有公开账号、实际路径、消息或密钥。该结果不代表自动回复或软件发送已通过实机验收，不同客户端、进程权限或数据库格式受限时仍会如实报错。

需要已安装的64位 Python 3.11或更新的3.x版本，并支持 `sqlite3.deserialize`。安装器先检查明确指定的解释器，再尝试 `py` 启动器和 PATH，只排除 WindowsApps 根目录的启动占位程序；商店包目录内真实解释器在版本和功能验证通过后可以使用，本机已确认Python3.11.9可用。找不到可用解释器时会提示你自行安装，不会安装系统 Python、改系统设置、自动提权或关闭防护。

安装器在 `.local-wechat/venv` 创建隔离环境，按上游 `requirements.txt` 安装锁定版本依赖，不向系统 Python 安装包。默认源码只进入 `.local-wechat/tools/`，已有未登记内容不会覆盖。解包使用Python标准库，不依赖PowerShell Archive模块，并拒绝越界路径、符号链接、重复路径及超出大小/数量限制的包。下载包、安装失败的暂存和日志保留在 `.local-wechat/`，不上传到云端。

## 复用已配置环境

可在自己的 PowerShell 中设置以下环境变量，再运行相应 CMD。这里仅为路径示意，请替换为自己的实际绝对路径，不要把真实账户路径和配置文件公开分享：

```powershell
$env:KEXU_EXPORTER_ROOT = 'D:\Tools\wechat-chat-export'
$env:KEXU_PYTHON = 'C:\Python311\python.exe'
$env:KEXU_WECHAT_DB_DIR = 'D:\WeChatData\xwechat_files\本人已选账户\db_storage'
& '.\安装微信提取组件.cmd'
```

`KEXU_EXPORTER_ROOT` 指包含 `SKILL.md`、`scripts/export_wechat.py` 和 `requirements.txt` 的已审核工具根目录。显式复用的源码版本由你管理，安装器不覆盖或自动更新它。`KEXU_PYTHON` 选择用于创建隔离环境的现有解释器；真正运行路径写为隔离环境的 `python.exe`。多账号应通过 `KEXU_WECHAT_DB_DIR` 指定本人已选择的 `db_storage`。

安装成功后仅在 `.local-wechat/config.json` 保存：

```json
{
  "exporterRoot": "工具源码绝对路径",
  "pythonPath": "本项目隔离环境Python绝对路径",
  "dbDir": "可选：已选账号db_storage绝对目录"
}
```

没有 `dbDir` 时由上游尝试定位；检测到多个账户时应先明确选择。网页不能修改命令或解释器路径。此配置不含数据库密钥，安装器也不调用vendor的 `extract`、`decrypt`、调试捕获或密钥写出命令。

## 业务数据导出

全局「导出数据」和设置页的数据管理入口可选择全数据JSON、客户CSV、消费CSV或跟进CSV。全数据JSON包含当前门店的聊天、画像、消费退款、任务、商品服务资料与回复规则，不含模型API Key；三个CSV分别下载，使用UTF-8 BOM，便于表格软件读取中文。

客户消费次数只统计已确认销售，已确认退款扣减净额；待确认和已排除记录不计净额或消费次数。导出只读取当前记录，不会确认交易或修改状态。

当前没有完整JSON备份的导入还原界面，因此它是业务资料导出，不能称为一键恢复。JSON也不包含本机发送器凭据、数据库密钥或后台运行队列文件；不要将全数据JSON误放进聊天导入入口。导出中含客户与聊天资料，保留在受控位置，不提交Git或公开分享。

## 数据和日志放在哪里

| 位置 | 用途 |
|---|---|
| `.wrangler/state/` | 本机 D1 客户、聊天、订单与任务 |
| `.dev.vars` | 本地应用加密密钥；首次创建，已有文件不覆盖 |
| `.local-wechat/config.json` | 受本地控制的工具、Python及可选账户路径 |
| `.local-wechat/d1-migrations.json` | 已应用迁移名称与内容摘要 |
| `.local-wechat/migration-pending.json` | 未确认完成的迁移保护标记，异常时不要直接删掉重跑 |
| `.local-wechat/logs/` | 安装与启动日志，已尽量隐藏已知密钥值 |

不要提交或对外分享以上文件及导出聊天。本地应用密钥与数据库一起保管，丢失或擅自更换加密密钥可能需要重新保存模型API Key。迁移目录通过journal排序，每项成功才登记；已有完整一致的表结构只登记，不重复执行建表。发现部分表、内容摘要变化、上次迁移未完成或迁移记录不一致时会停止并保留数据，等待人工核对。

本地模式服务仅绑定回环地址，不能让其他电脑通过局域网访问。关闭本地程序后，云端网页不能读取这台电脑的普通微信；需要本地提取时使用本地工作台。当前提取链路不向云端门店同步聊天；手动AI和主动启用的回复后台会把必要上下文发送到所选模型供应商。

## 本机回复后台

在商品与服务知识、FAQ、客户白名单和回复规则准备好之后，主动保存并启动本机回复服务。内置导出器约每30秒读取选中最多20位好友私聊的新文本，不追溯回复历史导入。默认只拟草稿，商户可审阅、拒绝、复制或接管客户；没有发送适配器时不能启动自动发送，批准发送也会被拒绝。

微信需保持登录、本地服务需保持运行，并配置有效AI Key。后台模式下可以关闭浏览器页面，处理仍由本地进程继续；关闭启动窗口或暂停回复后停止处理。启用前应明确这一持续读取和模型调用范围。

## 当前边界

- 只读取当前电脑已保存且有权访问的记录，不保证包含手机或其他电脑历史。
- 本工作台仅接收好友私聊，群聊和文件传输助手不归到某一位客户；图片、语音、视频只保留类型和已有描述。
- 合并转发、引用与支付卡片不能作为客户本人事实或营业收入凭证；消费、退款必须有可核对证据并由商家确认。
- 启动和组件安装都不自动提取微信；用户主动发起提取或启动白名单回复后台后，才运行指定范围的导出。
- 当前实机证据只覆盖上述1条自测回读，没有验收真实客户自动回复、自动发送或长时间无人值守。公开测试与回归只使用合成数据，不使用真实聊天或密钥。

## 开发者打包

```powershell
node scripts/package-local.mjs
```

生成 `public/kexu-local.zip`。包中只放运行所需源码、锁文件、入口和文档，排除依赖、构建产物、数据库、环境变量、密钥、日志、Git信息和本机工具。ZIP属于构建产物，不应提交源码仓库；`.env.example` 可作为无真实凭据的示例保留。

如不希望自动打开浏览器，可设置 `KEXU_NO_BROWSER=1` 后运行启动器，再手动访问显示的本机地址。
